# KabadiConnect

Realtime recycling marketplace starter built with Next.js, Tailwind CSS, Framer Motion, Express, Socket.IO and MongoDB.

## Start

1. Copy `server/.env.example` to `server/.env` and set `MONGODB_URI`.
2. Run `npm run install:all`.
3. Run `npm run dev` and open http://localhost:3000.

The AI scan in this starter uses a transparent demo classifier. Replace `POST /api/scans/analyze` with a vision provider or hosted waste-classification model before production.
